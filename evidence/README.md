# 证据归档规范

evidence/ 保存经过隐私检查、可复核的技术证据。公开仓库不得保存未经脱敏的原始终端输出、串口日志或网络状态快照。

## 分类

- uart/：经隐私检查的串口日志及其来源校验信息。
- hardware/：经过隐私检查的硬件识别、温度、内存、接口等证据。
- boot/：经过隐私检查的启动过程、启动器和内核启动证据。
- manifests/：证据清单、SHA-256、采集环境和来源说明；不得包含敏感原值。

## 公开归档规则

1. 原始未脱敏采集件只保存在受控的私人存储中，不提交公开仓库。
2. 公开仓库仅提交脱敏副本；脱敏不得改变技术事件顺序、错误信息、版本、时间戳及可复核的技术结论。
3. MAC、设备/CPU 序列号、分区/文件系统 UUID、唯一分区 GUID、账号、令牌、密钥、个人路径及家庭网络地址均须删除或替换为明确占位符；标准协议常量、芯片型号、寄存器地址及公开源代码哈希可保留。
4. 每份脱敏证据记录来源类别、采集时间（含时区）、设备/介质型号、镜像 SHA-256、串口参数或命令、脱敏范围和脱敏后文件 SHA-256；不得记录被删除的敏感原值。
5. 大文件不适合 Git 时，只有完成同等隐私审查后才可放入公开 Actions Artifacts 或 Releases；未经脱敏的内容只能存放在私人存储。
6. 不提交密码、访问令牌、私钥、个人敏感数据或可识别家庭网络的信息。
7. 不把推断写入证据；分析另存到 docs/reports/，并明确区分已验证、未验证和推测。
