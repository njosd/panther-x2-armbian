# 原始证据归档规范

evidence/ 保存原始测试输出和可复核证据，不保存分析性结论作为原始证据。

## 分类

- uart/：串口原始日志。
- hardware/：硬件识别、温度、内存、接口等原始输出。
- boot/：启动过程、启动器和内核启动证据。
- manifests/：证据清单、SHA-256、采集环境和来源说明。

## 归档规则

1. 原始文件保持原样，不编辑、不覆盖；需要脱敏时另存脱敏副本，并注明与原件关系。
2. 文件名包含日期、设备/版本、测试主题，例如 2026-11-15-panther-x2-6.12.81-uart-boot.log。
3. 每份证据记录来源、采集时间（含时区）、设备/介质、镜像 SHA-256、串口参数或命令、采集方式。
4. 同时记录 SHA-256；大文件不适合 Git 时放入 GitHub Actions Artifacts 或 Releases，并在清单中记录 URL、Artifact ID、Run ID 和校验值。
5. 不提交密码、访问令牌、私钥、个人敏感数据。
6. 不把推断写入原始日志；分析另存到 docs/reports/。
